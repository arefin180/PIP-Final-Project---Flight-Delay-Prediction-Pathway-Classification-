SAMPLE DATA -- NOT THE PROJECT DATASET
======================================

The file sample_flights.csv in this folder is INVENTED data,
created by src/make_sample_data.py.

It exists for ONE reason: to check that our code runs without
crashing before the real dataset is available.

DO NOT use any number, plot, table, or conclusion from this file
in the report, the presentation, or the viva.

The real dataset belongs in data/raw/, and config.USE_SAMPLE_DATA
must be set to False before producing any result for the report.
